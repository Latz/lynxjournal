# Post Templates

## Overview

LinkDigest lets you control the HTML output of every published link or digest post through a set of **Gutenberg-based templates**. Instead of hardcoded markup, you edit a normal WordPress post in the block editor — using LinkDigest's placeholder blocks — and the plugin substitutes real link data at publish time.

There are three templates, each covering a different part of the publishing pipeline:

| Template | Admin path | Controls |
|---|---|---|
| Link Template | LinkDigest › Link Template | Layout of individually-published link posts |
| Digest Item Template | LinkDigest › Digest Item Template | Each item row inside a grouped digest post |
| Digest Group Template | LinkDigest › Digest Group Template | The heading section above each category group in a digest |

All three editors require the `manage_options` capability (Administrator).

---

## Template Types

### Link Template

**When it applies:** When you publish a single link from the "All Links" table. One WordPress post is created per link; this template controls its structure.

**Admin path:** LinkDigest › Link Template

**Default content:**

```
[ Link Title ]
[ Description ]
[ Read More → ]
```

**Default output:**

```html
<h2>My Link Title</h2>
<p>The saved description text.</p>
<p><a href="https://example.com">Read more →</a></p>
```

---

### Digest Item Template

**When it applies:** For every individual link rendered inside a grouped digest post. The template runs once per link.

**Admin path:** LinkDigest › Digest Item Template

**Default content:**

```
[ Title → URL ]
[ Description ]
```

**Default output (per item, wrapped in `<li>` by PHP):**

```html
<a href="https://example.com" target="_blank" rel="noopener">My Link Title</a>
<p>The saved description text.</p>
```

---

### Digest Group Template

**When it applies:** Once per category group in a digest post — rendered immediately before the list of items in that group.

**Admin path:** LinkDigest › Digest Group Template

**Default content:**

```
[ Category H2 ]
```

**Default output:**

```html
<h2>Technology</h2>

<ul>
  <li>…item…</li>
  <li>…item…</li>
</ul>
```

> The `<ul>/<li>` wrapping is generated by PHP. You can control whether it becomes a `<ul>` or `<ol>` using the **Items List** block — see [Block Reference](#available-blocks) below.

---

## Available Blocks

LinkDigest registers the following blocks under the **Text** category in the block inserter. They only produce meaningful output when used inside a LinkDigest template post.

| Block | Editor label | Output | Typical template |
|---|---|---|---|
| `linkdigest/field-title` | Link: Title | `<h2>Title</h2>` | Link Template |
| `linkdigest/field-title-link` | Link: Title as Link | `<a href="…">Title</a>` | Digest Item Template |
| `linkdigest/field-url` | Link: URL | Raw URL string | Any |
| `linkdigest/field-description` | Link: Description | Rich HTML (safe tags) | Any |
| `linkdigest/field-read-more` | Link: Read More | `<p><a href="…">Read more →</a></p>` | Link Template |
| `linkdigest/field-tags` | Link: Tags | `<p>tag1, tag2, …</p>` | Any |
| `linkdigest/field-current-date` | Digest: Current Date | `<time datetime="…">…</time>` | Any |
| `linkdigest/field-category` | Category Heading | `<h1>`–`<h6>` (configurable) | Digest Group Template |
| `linkdigest/field-items-list` | Items List | *(none — sets list type)* | Digest Group Template |

### Current Date (`field-current-date`)

Outputs today's date at the moment the digest (or link post) is rendered. The date is formatted according to the site's **Settings › General › Date Format** and wrapped in a semantic `<time>` element with a machine-readable `datetime="YYYY-MM-DD"` attribute. No configuration is needed — just add the block and it always reflects the current date.

### Category Heading (`field-category`)

Outputs the category name as a heading. Select the block and use the **Heading level** dropdown in the toolbar to choose H1–H6. The default level is H2.

### Items List (`field-items-list`)

This block has no visible output of its own. When present in the Digest Group Template, it tells the plugin whether to wrap the items in a `<ul>` (bulleted) or `<ol>` (numbered) list. Use the **Unordered list** / **Ordered list** buttons in the toolbar to switch.

If the block is absent from the template, the plugin falls back to `<ul>`.

---

## Fallback Behaviour

Each block handles missing data gracefully:

* **field-title** / **field-title-link** — outputs nothing if the link title is empty.
* **field-title-link** — outputs the plain title (no link) if no URL is saved.
* **field-url** — outputs nothing if no URL is saved.
* **field-description** — outputs nothing if no description is saved.
* **field-read-more** — outputs nothing if no URL is saved.
* **field-tags** — outputs nothing if no tags are assigned.
* **field-category** — outputs nothing if no category name is available.
* **field-current-date** — always outputs a value (the current date is always known).

If a template post is missing entirely (e.g. deleted from the database), the plugin falls back to a minimal hardcoded layout:

* **Link Template fallback:** `<a href="url">Title</a>` + description
* **Digest Item fallback:** `<a href="url">Title</a>` + description (or plain title if no URL)
* **Digest Group fallback:** `<h2>Category Name</h2>`

## Customisation Examples

### Example 1: Add a "Read more" link to digest items

By default the Digest Item Template only shows the linked title and description. To add a source link at the end of each item:

1. Go to **LinkDigest › Digest Item Template**.
2. Click the **+** inserter and search for "Read More".
3. Add the **Link: Read More** block below **Link: Description**.
4. Click **Update** (or **Publish**).

The next digest will include `<p><a href="…">Read more →</a></p>` at the end of each item.

---

### Example 2: Change category headings to H3

1. Go to **LinkDigest › Digest Group Template**.
2. Select the **Category Heading** block.
3. In the toolbar, open the **Heading level** dropdown and choose **H3**.
4. Click **Update**.

---

### Example 3: Add the publication date to a digest group heading

1. Go to **LinkDigest › Digest Group Template**.
2. Click the **+** inserter and search for "Current Date".
3. Add the **Digest: Current Date** block above or below the **Category Heading** block.
4. Click **Update**.

The date is rendered using the format set in **Settings › General › Date Format**.

---

### Example 4: Use a numbered list for digest items

1. Go to **LinkDigest › Digest Group Template**.
2. If an **Items List** block is not already present, click **+** and add it.
3. Select the block and click the **Ordered list** button in the toolbar.
4. Click **Update**.

The next digest will wrap items in `<ol>…</ol>` instead of `<ul>…</ul>`.

## Resetting a Template

If you want to restore a template to its default content, the simplest approach is to clear the stored option from the database and let the plugin recreate it:

1. In the WordPress admin, go to **Tools › Database** (or use WP-CLI / phpMyAdmin).
2. Delete the option `linkdigest_template_single_link`, `linkdigest_template_digest_item`, or `linkdigest_template_digest_group` as appropriate.
3. Navigate to any LinkDigest admin page — the plugin will recreate the template post with default content on the next `admin_init`.

Alternatively, deactivating and reactivating the plugin triggers the same recreation for any missing template options.
